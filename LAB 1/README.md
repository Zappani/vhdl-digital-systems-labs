LAB 1 – Multiplexer with Memory

This project involves the implementation, in VHDL, of a digital system that combines combinational and sequential logic using a multiplexer coupled with a memory element.

An RTL module was developed capable of selecting, via control signals, one of multiple digital inputs and storing the selected value in a clock-synchronized register. This approach allows not only signal routing (characteristic of multiplexers) but also state retention over time.

The project includes:

Structural and/or behavioral description of the multiplexer;

Implementation of a register for storing the selected data;

Integration of the blocks into a single system;

Testbenches for functional validation;

Simulations for timing and logic verification of the circuit.

The main objective is to consolidate fundamental concepts of digital systems, such as signal selection, clock synchronization, and data storage, as well as to introduce validation practices using VHDL simulation.
